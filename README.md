The entry for this bounty is a post on X that quotes or links make.fun's make-your-own-bounty announcement and carries a photo. Ranking is decided by engagement on that post — replies, reposts, and quotes added together — and the top 50 entrants split a $250 prize pool. This repository only records where the post lives: `POST.json` holds the post's URL, and `main.ts` copies that file into the output directory for the gate to read.

## Run it

```bash
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
